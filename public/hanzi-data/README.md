# Hanzi stroke data

The website loads one character at a time from the version-pinned hanzi-writer-data@2.0.1 package. It tries jsDelivr first and unpkg as a fallback, so the character JSON files do not need to be stored in this repository.

Source: Hanzi Writer Data / Make Me a Hanzi. Stroke paths are unchanged.

https://github.com/chanind/hanzi-writer-data
